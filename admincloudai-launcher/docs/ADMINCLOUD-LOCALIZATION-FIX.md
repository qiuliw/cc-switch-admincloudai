# beta 0.3.1 汉化修复

日期：2026-10-12。核心版本仍为 CC Switch v4.0.9。

beta 0.3 在当前客户端中能启动进程，但界面保持英文。排查确认，安装的 Microsoft Store 客户端 26.1007.2314.0 请求语言层 72216192，而远程返回的层值为空。原钩子只按层中的字段识别语言配置，因而没有启用中文。另一个问题是状态检测只识别导航链接，当前客户端的内置侧栏操作已经改为按钮。

修复仅对已核对的语言层增加空值兼容，保留其他功能层；状态检测增加内置定时任务和插件按钮的身份检查。中文聊天、项目名称仍不能证明界面汉化成功。首页的“启动中文 ChatGPT”和“重启中文 ChatGPT”保持醒目位置。

实际验证中使用当前客户端已有的本机调试端口注入修复脚本，并刷新页面。客户端菜单和内置侧栏按钮变为中文，生产状态脚本返回 `locale-active`。没有结束客户端进程；完整关闭后重新启动的行为与不同客户端版本仍需分别验证。

20 项脚本回归及 14 项原生客户端测试通过。新增用例先在旧代码中失败，再在修复后通过，覆盖空语言层、旧钩子升级、新版侧栏按钮和中文用户内容的误判。

请使用 beta 0.3.1 程序。客户端已经运行且缺少受控调试时，先保存正在进行的工作，再点击首页“重启中文 ChatGPT”并确认；首次语言加载可能稍慢，等待后可点击“重新扫描”。汉化未得到实际中文界面证据时，仍显示等待验证。
